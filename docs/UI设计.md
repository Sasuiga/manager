# 手机竖屏 UI 设计文档

## 一、设计总则

1. **手机竖屏优先**
   - 所有界面以竖屏单手握持为基准设计。
   - 信息纵向排列，避免宽表格。
   - 高频操作放在拇指可触区域，底部固定关键导航。
   - 弹窗采用底部升起的全屏抽屉，代替 PC 式浮窗。

2. **维多利亚3风格**
   - 深色半透明面板、金铜描边、衬线标题、账本式数据行。
   - 卡牌与按钮像“公文 / 批文 / 委任状”。
   - 整体气质：工业时代内阁账本 + 企业经营仪表盘。

3. **信息分层**
   - 按钮上只放：动作 + 对象 + 最关键消耗 / 状态。
   - 弹窗里放：完整成本、即刻效果、资源变化、限制风险、确认操作。
   - 解释与引导文案放在按钮下方小字、弹窗顶部、首次引导、百科 / 日志中。

4. **双模式**
   - **经营模式**：显示预计值、缺口、可操作项，弱化会计科目。
   - **报表模式**：月底自动生成，完整展示利润表、资产负债表、现金流量、财务比率，每个科目可下钻。

5. **一切数字可下钻**
   - 现金、毛利、净利润、库存、净资产等旁边有“来源 / 公式”入口。
   - 点开显示：基础值、气候修正、事件修正、人员加成、卡牌效果、移动加权平均成本等。

6. **预测先行，结算后置**
   - 玩家在采购、生产、销售分配时，实时看到“预计现金、预计毛利、预计目标进度”。
   - 结算后才正式过账，避免月底才发现现金为负。

7. **AP 与打牌数分离**
   - AP 用于招聘、采购、签协议、供应商开发等。
   - 打牌不耗 AP，但占“每月可打牌数”。
   - UI 必须将两者分开显示。

## 二、整体竖屏结构

```text
┌──────────────────────────────┐
│ 3月 · Q1 · 复苏 · 扩张       │  ← 月份/季度/气候/经济动能
│ 💰42w  AP 3/4  牌 1/2  目标62%│  ← 核心资源，可点开下钻
├──────────────────────────────┤
│ [ 经营 ] [ 报表 ] [ 日志 ]    │  ← 三横列标签
├──────────────────────────────┤
│                              │
│        中间操作区            │
│        可上下滚动            │
│                              │
│  部门资源情况                │
│  功能区                      │
│  人员招聘 / 设备购买         │
│                              │
├──────────────────────────────┤
│ 运营 采购 生产 销售 研发      │  ← 仅经营页显示，固定底部
└──────────────────────────────┘
```

- 报表页和日志页时，底部部门轨道隐藏，换成对应的子标签或筛选栏。
- 报表页点科目，下钻用底部升起的全屏抽屉。
- 目标追踪固定在顶部资源区，点击后全屏展开。

## 三、顶部 HUD 与目标追踪

### 3.1 第一层：环境与时间

显示：
- 月份 / 季度
- 当前气候：复苏、繁荣、过热、滞涨、衰退、萧条
- 经济动能：扩张、收缩、停滞
- 下季度气候预测概率，可点开

作用：让玩家随时知道“这个月为什么需求高 / 原料贵”。

### 3.2 第二层：经营资源

优先显示：
- 现金
- AP
- 本月可打牌数
- 借款额度
- 目标进度

目标胶囊示例：

```text
目标：基本✅  挑战 62%  >
```

点击后全屏展开【目标追踪】。

### 3.3 目标追踪面板

每张目标卡显示：
- 目标名称
- 目标类型：基本 / 挑战
- 目标描述
- 当前值
- 目标值
- 进度条
- 状态图标
- 剩余差距

状态图标：
- ⏳ 进行中
- ✅ 已达标
- ❌ 未达标
- — 已失效

类型处理：
- **累计型**：当前值 = 本季度已过月份之和。
- **时点型**：当前值 = 最新余额。
- **条件型**：当前值 = 已完成次数。
- **比率型**：显示为“当前值 / 上限”，如“负债 10w / 上限 15w”。

挑战目标未选中的不追踪，但可在“董事会记录”中查看。

## 四、三标签页

### 4.1 经营页

主页面，底部固定五个部门轨道：

```text
运营 | 采购 | 生产 | 销售 | 研发
```

选中部门用金铜色高亮，未选中用暗色。  
每个部门页从上到下：

1. 部门相关资源情况
2. 功能操作区
3. 人员招聘 / 设备购买

### 4.2 报表页

顶部月份切换：

```text
[ 1月 ] [ 2月 ] [ 3月 ] ...
```

子标签：
- 利润表
- 资产负债表
- 现金流量表
- 财务比率

手机竖屏用账本列表，而非宽表格：

```text
销售收入        42w    >
销售成本        28w    >
毛利            14w    >
```

点开 `>` 后，底部升起明细抽屉，显示：
- 订单收入
- 现货收入
- 移动加权平均成本
- 气候 / 事件 / 卡牌修正
- 计算过程

财务比率只在月底报表展示。董事会目标用绝对数，比率型目标显示“当前值 / 上限”。

### 4.3 日志页

时间线形式：

```text
3月 · 事件：原料飞涨
3月 · 打出：批量采购
3月 · 结算：净利润 8w
3月 · 目标：挑战进度 80%
```

子标签：
- 全部
- 事件
- 董事会
- 结算
- 操作

每条日志可点开查看详情。日志可做成“内阁日报 / 公司纪事”风格。

## 五、底部部门轨道

五个部门：
- 运营部（对应管理部门）
- 采购部
- 生产部
- 销售部
- 研发部

底部轨道高度约 64px，加手机安全区。  
每个按钮：
- 图标
- 两字简称
- 未处理事项时右上角小红点或金色徽章

提示示例：
- 采购：有可签长期协议时亮起
- 生产：有原料可生产时亮起
- 销售：有订单未交付时亮起
- 研发：进度满可判定时亮起

## 六、部门页面通用结构

每个部门页面从上到下：

1. **部门相关资源情况**
   - 只显示该部门核心资源，不堆全局资源。
2. **功能操作区**
   - 按钮简洁：动作 + 对象 + 关键消耗 / 状态。
   - 细节在弹窗中。
3. **人员招聘 / 设备购买**
   - 招聘按钮 + 解锁槽。
   - 点击按钮弹出详细成本与效果。
   - 生产部额外包含设备购买列表。

## 七、各部门页面设计

### 7.1 运营部

**顶部资源：**
- AP
- 手牌上限
- 本月可打牌数
- 管理人数
- 抽卡 N 选 M
- 弃牌堆入口

**功能：**
- 查看手牌
- 打牌
- 弃牌
- 管理卡解锁
- 查看当前牌库 / 弃牌堆

**人员招聘：**
- 管理人员阶梯费用：5、4、3、2、1w
- 薪酬 1w
- 基础值：每招募一人，AP 上限 +1，下月可用
- 解锁：
  - 2人：可选卡牌 3→4
  - 3人：手牌上限 5→6
  - 4人：可打牌数 3，强化卡牌
  - 5人：可选 4→5，手牌 6→7，成就

### 7.2 采购部

**顶部资源：**
- 现金
- 本月可选档数
- 每类原料：包材、树脂、合金、芯片
- 市场供给、库存 / 上限、价格档位

**功能：**
- 现货采购：小批 / 中批 / 大批
- 贸易商
- 长期协议
- 供应商开发
- 新材料采购

**原料卡片示例：**

```text
包材
供给 24   库存 12/40
价格：基准
[小批] [中批] [大批]
```

**人员招聘：**
- 采购员 0~5
- 基础：每类原料供给 +2
- 解锁：
  - 1人：可选档数 +1
  - 2人：贸易商品种 +1
  - 3人：长期协议
  - 4人：所有原料价格降 1 档
  - 5人：双长期协议，6 个月，成就

### 7.3 生产部

**顶部资源：**
- 产能
- 设备数
- 生产人员
- 原料库存
- 折旧
- 借款额度

**功能：**
- 选择 BOM
- 生产
- 加班
- 设备购买

**设备卡片：**

```text
设备 A
产能 10  安置 1 人
折旧 2w/月
借款额度 5w / 3个月
[购买]
```

**人员招聘：**
- 生产员，薪酬 0.5w
- 基础：有设备坑位 +4 产能，无设备 +2
- 解锁：
  - 2人：每工人产能 +2
  - 3人：加班
  - 4人：每工人产能 +1
  - 5人：每 5 件额外入库 1 件，成就

### 7.4 销售部

**顶部资源：**
- 销售资源
- 订单
- 分层需求：低端 / 中端 / 高端 / 特殊
- 库存商品
- 售价档位
- 品牌加成

**功能：**
- 分配销售资源
- 订单交付
- 现货销售预览
- 清仓

**销售资源分配：**

```text

中端产品  [ - ] 2 [ + ]
```

底部实时显示：
- 预计销量
- 预计收入
- 预计毛利
- 目标进度变化

**人员招聘：**
- 销售员，薪酬 1.5w

  - 4人：每月 3 个订单
  - 5人：每人 +6 变 +8，成本转移，成就

### 7.5 研发部

**顶部资源：**
- 研发人数
- 当前项目进度
- 基础成功率
- 最终成功率

- 新材料供应

**功能：**
- 产品开发
- 技术开发
- 知识产权激活 / 替换
- 供应商开发

**项目卡片：**

## 八、按钮与弹窗规范

### 8.1 通用按钮模板

按钮最多两行：

```text
[ 动作 + 对象 ]
[ 关键消耗 / 状态 ]
```

示例：

```text
招聘采购人员
消耗 1 AP

采购包材 · 中批
1 档 · 约 12w

签订长期协议
1 AP + 1w

购买设备
5w

推进中端 BOM
进度 18/30

交付订单
10 件 · 价格 +1 档
```

原则：
- 不写解锁效果。
- 不写公式。
- 不写资源变化预览。
- 不写风险提示。
- 只保留一个最关键消耗，或一个最关键状态。

### 8.2 按钮状态

| 状态 | 表现 |
|---|---|
| 可操作 | 金铜描边，正常可点 |
| AP 不足 | 变灰，副行显示“AP 不足” |
| 现金不足 | 变灰，副行显示“现金不足” |
| 已达上限 | 变灰，副行显示“已满员 / 已满槽” |
| 本月已用 | 变灰，副行显示“本月已用” |
| 有可解锁 | 右上角小金点 |
| 有风险 | 右下角红色小三角，点击后弹窗内红色提示 |

### 8.3 通用弹窗模板

点击按钮后，底部升起全屏抽屉：

```text
┌──────────────────────────────┐
│ 签订长期协议                 │
│ 当前：协议 0/1               │
│                              │
│ 消耗                         │
│ AP              1            │
│ 手续费          1w           │
│                              │
│ 即刻效果                     │
│ 锁定一种原料，每月中批供应   │
│ 价格锁定 3 个月              │
│ 不占本月采购档数             │
│                              │
│ 资源变化                     │
│ 现金：42w → 41w              │
│ AP：3 → 2                    │
│ 协议：0/1 → 1/1              │
│                              │
│ [取消]        [确认签订]     │
└──────────────────────────────┘
```

弹窗必须包含：
1. 标题：动作 + 对象。
2. 当前状态 → 目标状态。
3. 消耗清单：AP、现金、原料、档数、槽位、手牌。
4. 即刻效果：基础值、解锁、生产、销售、研发。
5. 资源变化预览：旧值 → 新值。
6. 限制 / 风险：库存上限、现金为负、AP 不足、月限一次。
7. 取消 / 确认。

确认按钮可显示总消耗：

```text
[ 确认招聘（1AP + 3w） ]
```

### 8.4 招聘按钮与解锁槽

招聘区域放在部门页面最下方。

布局：

```text
人员招聘
┌──────────────────────────┐
│ 招聘采购人员             │
│ 消耗 1 AP                │
└──────────────────────────┘
当前 2 人 · 下次招聘费 3w

解锁轨道
①──②──③──④──⑤
✅ ✅ ⏳ ○ ○
档+1 贸易+1 协议 降价 双协议
```

- 按钮大字：招聘 XX 人员。
- 副行：消耗 1 AP。
- 按钮下方：当前人数、下次招聘费。
- 解锁槽横向排列，已解锁铜色填充，当前节点金色高亮，下一节点脉冲呼吸。
- 点击任意节点弹出该门槛详情。

### 8.5 招聘弹窗

点击招聘按钮后，底部升起全屏抽屉：

```text
┌──────────────────────────────┐
│ 招聘采购人员                 │
│ 当前 2 人 → 3 人             │
│                              │
│ 消耗                         │
│ AP              1            │
│ 招聘费          3w           │
│ 月度薪酬        +1w/月       │
│                              │
│ 即刻效果                     │
│ 每类原料供给 +2              │
│ 解锁：长期供货协议           │
│                              │
│ 招聘后                       │
│ 现金：42w → 39w              │
│ AP：3 → 2                    │
│                              │
│ [取消]        [确认招聘]     │
└──────────────────────────────┘
```

各部门招聘弹窗要点：

| 部门 | 招聘费 | 月度薪酬 | 即刻效果 | 特别注意 |
|---|---:|---:|---|---|
| 运营部 | 5/4/3/2/1w | 1w | 下月 AP 上限 +1 | 明确写“下月生效” |
| 采购部 | 5/4/3/2/1w | 1w | 每类原料供给 +2 | 达到 3 人解锁长期协议 |
| 生产部 | 无 | 0.5w | 有设备坑位产能 +4，无坑位 +2 | 显示当前空置设备坑位 |
| 销售部 | 5/4/3/2/1w | 1.5w | 销售资源立即增加 | 第 3、5 人会回溯提升总资源 |
| 研发部 | 5/4/3/2/1w | 2w | 本月研发进度 +2，成功率 +5% | 达到 3 人解锁第二知识产权槽 |

## 九、抽卡环节 UI

### 9.1 设计原则

- 列表式卡牌，从上往下排列。
- 效果直接写在卡牌上，默认展开。
- 不需要点击查看详情。
- 名字只做辅助，效果为主。

## 十一、动态效果设计

### 11.1 动效原则

- **克制而华丽**：维多利亚3气质偏厚重、机械、公文感，动效不能像霓虹赛博，而应像铜质齿轮、墨水扩散、纸张翻页、仪表指针。
- **信息优先**：动效服务于状态变化，不遮挡数字，不延迟操作。
- **手机竖屏适配**：以纵向滑动、底部升起、横向切换为主，避免复杂 3D 旋转。
- **性能可控**：默认 60fps，粒子数量限制，低端机可自动降级。
- **可关闭**：设置中提供“完整动效 / 简化动效 / 关闭动效”。

### 11.2 全局转场

- **三标签切换**：经营 / 报表 / 日志之间横向滑动切换，底部标签指示器同步滑动，内容淡入 + 轻微视差。
- **部门切换**：底部部门轨道选中时，金铜色高亮从旧部门滑向新部门，中央操作区从右侧或左侧滑入。
- **弹窗出现**：从底部升起，背景模糊 + 暗化，弹窗顶部羊皮纸区域先亮起，再展开内容。
- **弹窗关闭**：向下滑出，背景模糊恢复，伴随轻微惯性。
- **页面加载**：深色背景上先浮现铜色线条框架，再逐行显示内容，像账本被翻开。

### 11.3 顶部 HUD 动效

- **现金变化**：
  - 增加：数字向上滚动，绿色微光上浮。
  - 减少：数字向下滚动，红色微光下沉。
  - 大额变化：数字短暂放大，伴随铜色粒子。
- **AP 变化**：
  - 消耗：蓝色脉冲扩散，AP 数字从 `3` 跳到 `2`。
  - 增加：蓝色光点从按钮飞向 AP 胶囊。
- **目标进度**：
  - 进度条填充时，金铜色光带从左向右流动。
  - 达标瞬间：进度条闪烁，✅ 图标弹出，顶部胶囊短暂金色高亮。
  - 未达标：季度结束时目标卡边缘红色脉冲。
- **气候与经济动能**：
  - 气候图标缓慢旋转，背景色调随气候渐变。
  - 经济动能箭头有轻微呼吸效果。

### 11.4 按钮与弹窗动效

- **按钮按下**：
  - 轻微缩放至 97%，金铜色涟漪从点击位置扩散。
  - 禁用按钮：灰色，点击时轻微震动，副行文字闪烁提示原因。
- **确认按钮**：
  - 可点击时金铜色流光扫过。
  - 点击后按钮短暂变暗，弹窗向下滑出。
- **资源变化预览**：
  - 旧值灰色划出，新值金色或红色弹入。
  - 现金减少时，数字旁有红色小箭头向下。
- **风险提示**：
  - 弹窗内红色警告文字脉冲，确认按钮短暂禁用，需再次点击或勾选“已知晓”。

### 11.5 卡牌与抽卡动效

- **抽卡列表**：
  - 卡牌从上到下逐张滑入，间隔 50ms。
  - 每张牌左侧类型色条先亮起，再显示效果文字。
- **选中卡牌**：
  - 金边发光，卡牌轻微上浮，右侧按钮变为“已选”。
  - 强化卡选中时，金色微粒从卡面飘出。
- **未选中卡牌**：
  - 选满后，未选卡牌变暗并轻微缩小。
- **确认选择**：
  - 已选卡牌飞向手牌区域，未选卡牌淡出并回到牌库。
- **弃牌**：
  - 被弃卡牌向下滑出屏幕，进入弃牌堆图标，图标短暂跳动。
- **手牌查看**：
  - 底部抽屉升起，手牌列表逐张展开。

### 11.6 部门轨道与解锁槽动效

- **部门轨道**：
  - 选中部门时，底部按钮放大 110%，金铜色描边亮起。
  - 有未处理事项时，右上角红点脉冲。
- **解锁槽**：
  - 已解锁节点：铜色填充，点击时轻微震动。
  - 当前节点：金色高亮，呼吸光效。
  - 下一节点：脉冲提示，连线从左向右流动。
  - 新解锁瞬间：节点爆出铜色光环，连线快速填充，部门按钮小红点闪烁。

### 11.7 事件与气候动效

- **事件卡翻开**：
  - 卡牌从背面翻转，背面是铜质纹章。
  - 正面根据极性显示不同光效：
    - 正面：金色微光。
    - 负面：暗红雾气。
    - 中性：灰蓝墨水扩散。
- **气候切换**：
  - 每季度开始时，屏幕背景色调渐变到新气候。
  - 复苏：绿色嫩芽粒子。
  - 繁荣：金色光尘。
  - 过热：红色热浪扭曲。
  - 滞涨：灰雾缓慢流动。
  - 衰退：蓝色雨丝。
  - 萧条：暗色雪花。
- **抉择事件**：
  - A / B 按钮出现时，左右滑入。
  - 悬停或按住时，显示代价与收益的浮动标签。

### 11.8 报表与结算动效

- **月底结算**：
  - 屏幕中央出现铜质印章，盖下后报表逐行生成。
  - 利润表、资产负债表、现金流量表依次滑入。
- **数字滚动**：
  - 每个科目数字从 0 滚动到最终值，间隔 30ms。
  - 正数绿色，负数红色，毛利金色。
- **科目下钻**：
  - 点击科目行，底部抽屉升起，明细逐行展开。
  - 计算过程像墨水书写一样逐字显示。
- **现金为负**：
  - 屏幕边缘红色脉冲，报表标题闪烁，游戏结束按钮出现。
- **目标结算**：
  - 达标目标卡金色对勾弹出，未达标红色叉号弹出。
  - 连续两次未达标时，屏幕暗下，红色警告文字浮现。

### 11.9 性能与可访问性

- **默认动效**：完整动效，60fps。
- **简化动效**：关闭粒子、缩短转场、数字直接跳变。
- **关闭动效**：所有转场改为淡入淡出，无粒子，无脉冲。
- **低端机自动检测**：帧率低于 45fps 时自动降级粒子数量。
- **可访问性**：
  - 动效不依赖颜色单独传递信息，配合图标与文字。
  - 重要状态变化有轻微震动反馈，可关闭。
  - 所有动效时长控制在 150ms ~ 400ms，不阻塞操作。

## 十二、引导与帮助

按钮上不写解释。引导文案分三层：

1. **按钮下方一行小字**
   - 只在未解锁或首次出现时显示。
   - 例如：“还差 1 人解锁长期协议。”

2. **弹窗顶部一句说明**
   - 例如：“长期协议不占本月采购档数。”
   - 例如：“运营人员下月才增加 AP 上限。”

3. **首次引导 / 百科 / 日志**
   - 首次进入部门时，用半透明蒙层指向按钮。
   - 之后可在日志页或百科中查看。
